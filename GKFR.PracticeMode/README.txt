Practice Mode Mod
=================

No countdown, no lap limit, instant-respawn toggle, key-to-restart.

Controls:
- F4   toggle practice mode on/off
- R    restart race

Configuration:
- Enabled (default: true) - Master switch
- ToggleKey (default: F4) - Key to toggle practice mode
- RestartKey (default: R) - Key to restart race
- NoCountdown (default: true) - Disable countdown before race starts
- NoLapLimit (default: true) - Disable lap limit
- InstantRespawn (default: true) - Instant respawn on crash

Removes race restrictions for practice sessions.
