No Items Mod
============

Restrict which items boxes can give (the item pipeline is already hooked by ItemMultiplier).

Controls:
- F6   toggle no-items on/off

Configuration:
- Enabled (default: true) - Master switch
- ToggleKey (default: F6) - Key to toggle no-items
- DisableAllItems (default: false) - Disable all items completely  
- WhitelistItems (default: "") - Comma-separated list of item names to allow (empty = all disabled)

Prevents items from spawning in boxes, or allows only specific items to spawn.
