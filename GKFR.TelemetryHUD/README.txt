Telemetry HUD Mod
=================

Speed, boost level, drift charge, gear, slipstream overlay (extends LapTimes).

Controls:
- F3   toggle telemetry HUD on/off

Configuration:
- Enabled (default: true) - Master switch
- ToggleKey (default: F3) - Key to toggle telemetry HUD
- ShowSpeed (default: true) - Show speed information
- ShowBoost (default: true) - Show boost level  
- ShowDrift (default: true) - Show drift charge
- ShowGear (default: true) - Show gear information
- ShowSlipstream (default: true) - Show slipstream information

Displays real-time telemetry data including speed, boost, drift charge, gear, and slipstream status on screen.
