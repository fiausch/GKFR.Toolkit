Debug Item Spawner Mod
======================

Press number keys to give yourself any item (pie, boost, UFO) via KartBonusMgr.DoSetItem.

Controls:
- 1-9  give item (1=pie, 2=boost, 3=UFO, 4=banana, 5=shell, 6=mushroom, 7=lightning, 8=star, 9=flower)

Configuration:
- Enabled (default: true) - Master switch
- Item1Key (default: 1) - Key to give pie item
- Item2Key (default: 2) - Key to give boost item  
- Item3Key (default: 3) - Key to give UFO item
- Item4Key (default: 4) - Key to give banana item
- Item5Key (default: 5) - Key to give shell item
- Item6Key (default: 6) - Key to give mushroom item
- Item7Key (default: 7) - Key to give lightning item
- Item8Key (default: 8) - Key to give star item
- Item9Key (default: 9) - Key to give flower item

Spawns items directly into your kart using the game's item system.
