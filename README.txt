GKFR Toolkit
============

A collection of mods for the game GKFR (Grand Karting Freedom Racing).

This toolkit contains various utility and enhancement mods that can be enabled/disabled through the ModLoader.

Mods included:
- Godmode - Makes karts invincible to damage with multiple targeting modes
- FOV - Wider FOV and pushed far-clip for a less claustrophobic view
- Debug Item Spawner - Press number keys to give yourself items 
- Telemetry HUD - Speed, boost level, drift charge, gear, slipstream overlay
- No Items - Restrict which items boxes can give
- Checkpoint Teleporter - Teleport to start/last/next checkpoint

Controls:
- F5: Godmode toggle (cycles through modes)
- F6: No Items toggle
- F7/F8/F9: Checkpoint teleportation
- F12: FOV adjustment toggle
- F3: Telemetry HUD toggle
- 1-9: Debug item spawner

Configuration:
All mods support configuration via the ModLoader window or by editing their respective config files.
