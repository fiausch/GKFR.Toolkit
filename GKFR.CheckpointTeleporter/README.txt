Checkpoint Teleporter Mod
=========================

Teleport to start / last / next checkpoint via RaceStats.

Controls:
- F7   teleport to start
- F8   teleport to last checkpoint  
- F9   teleport to next checkpoint

Configuration:
- Enabled (default: true) - Master switch
- ToStartKey (default: F7) - Key to teleport to start
- ToLastKey (default: F8) - Key to teleport to last checkpoint
- ToNextKey (default: F9) - Key to teleport to next checkpoint

Teleports your kart to different checkpoints in the race using dedicated keys.
